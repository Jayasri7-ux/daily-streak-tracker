# 📘 Daily Engineering & Learning Log

Continuous engineering activity log tracking daily system design notes, React/JavaScript patterns, API architecture reviews, and developer tooling updates.

## 📂 Structure

* [`DAILY_LOG.md`](./DAILY_LOG.md) — Human-readable table of recent engineering focus sessions.
* [`activity_log.json`](./activity_log.json) — Structured JSON log of timestamped study & coding entries.
* [`auto_streak.py`](./auto_streak.py) — Python CLI sync utility that formats and records daily engineering logs.
